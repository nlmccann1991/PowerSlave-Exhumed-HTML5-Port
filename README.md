# powerslaveexhumedhtml5
A browser (WebGL2 + WebAudio) port of PowerSlave Exhumed. It runs the game's own content straight from your copy of the game: maps, textures, sprites, sounds, music, definitions and the AngelScript game scripts. No game data is included; a legal digital copy of Powerslave Exhumed is required. I recommend GOG to get the game legally.
